Sistema de Apoio à Produtividade e Organização para Pessoas com Transtorno do Déficit de Atenção e Hiperatividade

Descrição:

Este projeto consiste no desenvolvimento de uma aplicação web voltada ao apoio à organização e à produtividade de pessoas com Transtorno do Déficit de Atenção e Hiperatividade (TDAH).

A aplicação busca oferecer diferentes ferramentas e modelos de organização, permitindo que o usuário escolha quais recursos deseja utilizar de acordo com suas necessidades e preferências. O sistema tem como proposta oferecer uma experiência flexível, possibilitando a utilização de diferentes estratégias para o gerenciamento de tarefas, planejamento de atividades e organização da rotina.

Funcionalidades:

- Gerenciamento de contas de usuário.
- Criação e gerenciamento de espaços de organização.
- Seleção de diferentes modelos de organização.
- Gerenciamento de tarefas e atividades.
- Personalização dos recursos utilizados de acordo com as preferências do usuário.

Observação: a lista de funcionalidades deve ser atualizada conforme os recursos efetivamente implementados no sistema.

Tecnologias Utilizadas

- React
- JavaScript
- Node.js
- Express
- PostgreSQL
- Tailwind CSS

Pré-requisitos

- Node.js instalado
- npm instalado
- PostgreSQL instalado e configurado

Como Executar

1. Clone o repositório.
2. Instale as dependências do frontend.
> cd frontend
> npm i
3. Instale as dependências do backend.
> cd backend
> npm i
4. Configure as variáveis de ambiente.
5. Inicie o servidor e a aplicação.
> npm start
